Suivi de dépenses Erasmus à Lisbonne

Maquettes de l'application : une PWA sur iPhone et un site web sur Mac, avec les mêmes données.

Le design est pensé mobile first : les écrans iPhone sont la référence, les écrans Mac en sont l'adaptation. Les boutons et les menus sont cliquables d'un écran à l'autre. Tous les chiffres sont des données d'exemple.

iPhone

Écrans de référence, à 390 px de large. Touche le bouton « + » du dashboard pour ouvrir la saisie, une dépense de l'historique pour la modifier.
